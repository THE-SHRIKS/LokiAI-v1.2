## Objective

Implement local policy decisions and immutable, expiring, single-use human
approvals bound to the canonical request, Windows principal, operation, target,
artifact, and parameters. Cloud RBAC remains deferred and unavailable.

## Dependencies and reading

- Accepted: `JOB-001`, `LOC-001`, `ADR-0002`
- Read: `AGENTS.md`, `Docs/SECURITY.md`, `Docs/SPEC.md` policy/approval/job
  sections, `Docs/TESTING.md`, and ADR-0002.

## Ownership

- Allowed: new `crates/loki-approvals/**`, workspace manifest/lockfile,
  packet/evidence/handoff.
- Forbidden: device/build execution, cloud roles, renderer confirmation UI,
  arbitrary policy expressions, mutable approval binding, or implicit success.

## Acceptance criteria

1. Closed policy rules return allow, approval-required, or deny; unknown
   operations default deny.
2. Approval-required requests use an unambiguous canonical encoding and SHA-256
   digest bound to principal, operation, target, artifact (including absence),
   parameter digest, and idempotency key.
3. Creation and grant require a live LOC-001 owner session. Grant never changes
   bound fields and records confirming principal/time.
4. Consumption atomically validates exact digest/fields, granted state, expiry,
   principal, and unused state. Mutation, reuse, races, expiry, denial, and wrong
   principal fail closed.
5. Approval metadata is durable and auditable; no bearer secret or cloud role is
   persisted.
6. Focused and full workspace gates pass with warnings denied.

No operation execution or physical device effect is authorized by this node.
