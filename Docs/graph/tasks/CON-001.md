# Task Packet — `CON-001 Connector SDK`

Packet status: `accepted`
Graph status: `ready` — dispatching
Starting revision: `1c465aa` (branch `LokiAI-v1.2`, pushed)

## 1. Objective

New crate `crates/loki-connectors-sdk`: the device-neutral connector trait and
supporting contracts — manifest shape, capability declaration, health-check
interface, operation lifecycle (preflight/execute/verify), and recovery hooks —
per `Docs/CONNECTOR_SPEC.md`. This is the SDK/trait definition only. No concrete
device connector (ESP32-S3 is `CON-003`, blocked on `OQ-001`) and no discovery
engine (`CON-002`). A conformance test harness that a fake/mock connector can be
run against to prove trait compliance is this node's proof of design.

## 2. Traceability

Requirements: `FR-CON-001`. Architecture: `Docs/CONNECTOR_SPEC.md` (full),
`Docs/ARCHITECTURE.md` (connector process boundary — device access lives in the
Rust runtime, never the renderer). Parent: `CTR-001`.

## 3. Dependencies and inputs

`depends_on`: `CTR-001` (accepted). Mirror `packages/contracts`' connector
vocabulary (support tier, capability risk, health status, capability descriptor
— already defined in `packages/contracts/src/connector.ts`) as Rust types citing
the same `Docs/CONNECTOR_SPEC.md` sections, same "no divergent copy" discipline
as `DAT-001`.

## 4. Required reading

`AGENTS.md`; `Docs/CONNECTOR_SPEC.md` (full); `Docs/ARCHITECTURE.md`;
`packages/contracts/src/connector.ts` (read-only, for the vocabulary to mirror).

## 5. Ownership

Writable: `crates/loki-connectors-sdk/**` (new); one `Cargo.toml` members line.
Forbidden: no concrete connector implementation; no discovery/registry logic
(`CON-002`); no physical device I/O of any kind — this crate defines the
contract shape and a conformance harness, nothing device-facing.

## 6. Deliverables

1. `crates/loki-connectors-sdk/Cargo.toml`, dependency-justified
2. The connector trait: manifest, capability descriptor, health-check method,
   operation lifecycle (preflight → execute → verify, with explicit
   success/failure/timeout outcomes — no operation may report success from
   process-exit alone, per `AGENTS.md` rule 6)
3. Support-tier and capability-risk enums mirroring
   `packages/contracts/src/connector.ts`
4. A minimal in-memory mock/fake connector implementing the trait, used only by
   this crate's own tests — proof the trait is actually implementable and
   testable, not just declared
5. A conformance test harness (a reusable test-suite function or macro any
   future concrete connector can run against its own implementation) covering:
   successful operation lifecycle, a preflight failure short-circuiting
   execute, a mid-execute failure, a verify failure after apparently-successful
   execute, and a timeout
6. Worker handoff at `Docs/graph/handoffs/CON-001-1.md`
