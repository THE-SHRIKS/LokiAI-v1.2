# Task Packet — `AGT-001`

Status: `accepted for implementation`

## Objective

Implement locally authorized, scoped, revocable coding-agent connections and a
durable run/parent-child/tool/change event registry. MCP transport initialization
alone grants no connection or operation authority.

## Dependencies and reading

- Accepted: `MCP-002`, `LOC-001`, `ADR-0002`
- Read: `AGENTS.md`, `Docs/MCP_SPEC.md`, `Docs/SECURITY.md`, `Docs/SPEC.md`
  agent/run sections, `Docs/TESTING.md`, ADR-0002.

## Ownership

- Allowed: new `crates/loki-agents/**`, workspace manifest/lockfile,
  packet/evidence/handoff.
- Forbidden: provider-specific core behavior, cloud wake/resume, arbitrary tool
  authority, device/build execution, renderer changes, or plaintext credentials.

## Acceptance criteria

1. Registration requires live LOC-001 `RegisterAgent`; connection scope is a
   validated allowlist and unknown scopes default deny.
2. A high-entropy secret is returned once; only its SHA-256 hash is stored and
   verification is constant-time. Revocation immediately invalidates it.
3. Runs use stable IDs, optional parent run constrained to the same connection,
   explicit states/transitions, UTC epoch times, correlation IDs, and durable
   idempotent registration.
4. Tool/change events are append-only, bounded, sequence-ordered, and rejected
   for revoked/wrong connections, unknown runs, duplicate sequence, or terminal
   runs.
5. Restart, secret mismatch, scope denial, revocation, parent mismatch,
   transition, idempotency, ordering, malformed input, and concurrency tests pass.
6. Focused and full workspace gates pass with warnings denied.

No cloud delivery or consequential operation execution is authorized.
