## 1. Objective

Implement a production, provider-neutral local work-intent delivery coordinator
that lets an explicitly scoped and authenticated AGT-001 connection claim an
incident work intent, acknowledge it only with a run owned by that connection,
expire it durably, or record an honest human-action fallback through LNOT-001.
It adds no cloud/remote wake path and grants no operation, device, or approval
authority.

## 6. Deliverables

1. Encrypted durable delivery state with the exact SPEC 4.10 local transitions.
2. Authenticated local claim and acknowledgement linked to an owned agent run.
3. Durable expiry and human-action fallback that enqueues LNOT-001 once.
4. Retry/race/restart/revocation/expiry tests, evidence, and handoff.

## 7. Acceptance criteria

- [ ] Only an active connection with explicit `ReceiveWorkIntents` scope can
  claim; wrong secret, missing scope, and revoked connection fail closed.
- [ ] Claim is atomic/idempotent, increments attempts once, and returns the
  original bounded intent without adding authority.
- [ ] Acknowledgement requires a run owned by the claiming connection and
  records the link; cross-connection runs and illegal/stale transitions fail.
- [ ] No eligible safe local path records `UserActionRequired` and creates one
  deduplicated LNOT-001 human notification.
- [ ] Queued/delivered intents expire durably; terminal states never regress.
- [ ] Encrypted restart preserves state and plaintext markers are absent.
- [ ] Full repository verification passes with no new lint errors.
