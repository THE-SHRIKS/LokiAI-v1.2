## 1. Objective

Implement `loki_connectors_sdk::Connector` for the confirmed ESP32-S3 (QFN56
rev v0.2, 8MB embedded PSRAM AP_3v3, 16MB external quad flash, 3.3V,
USB-Serial/JTAG native — `Docs/CONTEXT.md` OQ-001 row) as a new workspace
crate: manifest, capability declarations, health-check logic, and the
identify/preflight/execute/verify/recover STRUCTURE for this device family —
fully testable via an injected fake transport, with zero real device I/O
reachable from this node's own code or tests. This is the first concrete
connector in the codebase; it must not weaken any `loki-connectors-sdk`
guarantee (verify-only success, honest health/unavailable-with-reason,
identity evidence never fabricated).
