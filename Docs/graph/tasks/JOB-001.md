## 1. Objective

Durable job state machine in `crates/loki-jobs`: staged execution (preflight →
execute → verify per `AGENTS.md` rule 6 — no success inferred from process exit
alone), idempotency keys, per-device lease with expiry/renewal, and
cancel/restart/reconcile/quarantine transitions. Built on `DAT-001`'s SQLite
repositories (a new `jobs`-adjacent table/migration if needed — coordinate with,
don't duplicate, `DAT-001`'s existing `jobs` schema) and `RUN-002`'s IPC deadline/
cancellation primitives conceptually (this node doesn't wire IPC itself — that's
`MCP-003`/`OPS-001` later).

## 2. Dependencies and ownership

`depends_on`: `DAT-001`, `RUN-002` (both accepted). Writable: `crates/loki-jobs/**`
(new) + one `Cargo.toml` members line. Do not touch `crates/loki-storage/**`
directly — if the existing `jobs` table needs a column, add a new migration file
in `crates/loki-storage/migrations/`, don't edit an already-shipped one.

## 3. Required reading

`AGENTS.md`; `Docs/ARCHITECTURE.md` (jobs bounded context); `Docs/SPEC.md` (job

## 4. Deliverables and acceptance criteria

1. Job lifecycle: created → leased → running → (verify) → completed/failed, with
   explicit `quarantine` for an unknown/ambiguous outcome (crash mid-job,
   ambiguous verify) — never silently marked success or silently dropped.
2. Idempotency: submitting the same idempotency key twice does not create a
   duplicate job or duplicate side effect.
3. Lease: per-device, with expiry; a lease that isn't renewed is reclaimable by
   another attempt; two concurrent attempts for the same device cannot both hold
   a lease.
4. Cancel/restart: a running job can be cancelled (cooperative, not a kill -9
   assumption) and a failed/quarantined job can be explicitly restarted.
5. Real tests: crash-mid-job leaves a quarantined (not falsely-completed) state;
   a race for the same device lease has exactly one winner; retrying with the
   same idempotency key is a no-op; an unknown outcome after a crash is
   quarantined, never guessed as success or failure.
6. `cargo build/fmt/clippy/test --workspace` all pass (workspace now has 5
   crates — verify all five together, not just this one in isolation).
7. Worker handoff at `Docs/graph/handoffs/JOB-001-1.md`.
