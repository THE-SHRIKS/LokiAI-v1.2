## 1. Objective

Establish the first real Rust crate — `crates/loki-runtime` — as a standalone
executable with a health check, structured (JSON) diagnostics/logging via
`tracing`, graceful shutdown on signal, and clear module boundaries for the
domain logic that later nodes (`RUN-002` IPC, `DAT-001` storage, `JOB-001` jobs,
etc.) will add. This node proves the Rust toolchain end-to-end and gives the
(currently empty) root Cargo workspace its first member — `cargo build/test/fmt`
stop honestly skipping and start actually running from this node onward.

## 6. Deliverables

1. `crates/loki-runtime/Cargo.toml` — binary crate, workspace-inherited
   version/edition/rust-version, minimal reviewed dependency set (Tokio with
   only the features needed, `tracing` + `tracing-subscriber` with JSON
   formatting, a signal-handling crate appropriate for Windows — document why
   each is needed per `AGENTS.md` rule 11)
2. `crates/loki-runtime/src/main.rs` + module structure — clear separation
   between process bootstrap (main.rs) and domain/module boundaries (even if
   those modules are near-empty stubs right now, name them per
   `Docs/ARCHITECTURE.md`'s intended structure so later nodes have a place to
   land, not a monolith)
3. Structured JSON logging via `tracing`, correlation-ready (a request/run ID
   field even if nothing populates it yet)
4. A health mechanism — for a standalone binary with no IPC yet, this can be as
   simple as a `--health-check` CLI mode or a logged periodic heartbeat; do not
   invent a network listener prematurely (that's `RUN-002`'s job)
5. Graceful shutdown on Ctrl-C/SIGTERM-equivalent (Windows: console control
   handler) — logs a clean shutdown message and exits 0, not a hang or panic
6. Real tests: startup succeeds, shutdown signal is handled gracefully, an
   injected/simulated crash path is handled without a silent hang, malformed
   CLI args produce a clear error not a panic
7. Root `Cargo.toml` gains this crate as its first workspace member
8. Worker handoff at `Docs/graph/handoffs/RUN-001-1.md`
