# Verification evidence registry

Create evidence indexes at `<wave>/<NODE-ID>/README.md` only after the associated
checks run. Each index records the source revision, exact command or procedure,
UTC time, environment or certified device identity, result, reviewer, artifact
location, and digest where applicable.

Keep secrets, customer/device payloads, signing material, and bulky raw output in
the approved protected evidence store. This repository contains only redacted
indexes and verifiable references. An unexecuted check has no evidence entry.

No implementation evidence has been accepted yet.
