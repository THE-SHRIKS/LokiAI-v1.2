## 7. Decisions and assumptions

- The three accepted bounded-context database files remain separate and each
  has its own DPAPI-protected key sidecar.
- SQLCipher's Online Backup API rejects cross-codec copies; migration/rotation
  therefore use SQLCipher's native `sqlcipher_export`, verified by adversarial
  tests. Same-key core backups remain supported and are now verified inside the
  API.
- Optional `cipher_memory_security=ON` was not retained because real Windows
  execution exhausts `VirtualLock` quota (`LastError=1453`) and crashed a
  corruption test. Full database/WAL/backup encryption, DPAPI, buffer wiping,
  and fail-closed key handling remain enabled.
